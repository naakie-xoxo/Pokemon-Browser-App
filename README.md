# Pokemon Browser App

A React Native Expo Pokédex application created for **DCIT 324 Mobile Application Development — Assignment 4**.

## Features

- Live Pokémon list from PokéAPI
- Reusable Pokémon cards using props
- Favourite toggling using state
- Loading and error states
- Pokémon Details screen with type, height, and weight
- Stack navigation between Home and Details
- Bottom Tabs for Home and About
- Drawer links for Pokédex, Settings, Help & Support, and Logout

## Data source

Pokémon information is fetched live from [PokéAPI](https://pokeapi.co/) rather than being hard-coded.

## Run the project

```bash
npm install
npx expo start
```
